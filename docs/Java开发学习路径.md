## Java端开发学习路径

根据负责的模块：**Java后端、AI集成、前端界面、数据库设计，按项目进度分阶段学习**。

---

### 第1-2周：Java后端基础与数据库交互

**目标**：搭建Spring Boot项目，实现配置管理的REST API，能够操作MySQL。

| 学习内容                        | 具体知识点                                                   | 用于完成的任务                           |
| ------------------------------- | ------------------------------------------------------------ | ---------------------------------------- |
| **Spring Boot基础**             | 项目创建（Spring Initializr）、`@RestController`、`@GetMapping/@PostMapping`、`application.properties`配置 | 搭建后端骨架，提供配置管理API            |
| **Maven/Gradle**                | 依赖管理、构建命令（`mvn clean package`）                    | 管理项目依赖（MySQL驱动、连接池等）      |
| **数据库访问（JDBC Template）** | 配置数据源、`JdbcTemplate`的`query()`、`update()`操作，处理结果集 | 编写ConfigDAO，实现增删改查              |
| **MySQL基础复习**               | 建表、索引、外键、JSON类型                                   | 设计数据库表结构                         |
| **REST API设计规范**            | HTTP方法、状态码、JSON格式、接口文档编写                     | 定义前后端API接口，与C++同学约定数据格式 |
| **Postman**                     | 发送HTTP请求，测试API                                        | 调试自己写的接口                         |

**第2周结束检查点**：
- [ ] 能创建一个Spring Boot项目，运行后访问`/hello`返回JSON
- [ ] 能通过JdbcTemplate查询数据库并返回数据
- [ ] 已完成配置管理的CRUD API，并用Postman测试通过
- [ ] 与C++合作者初步商定了数据交换格式（JSON结构）

---

### 第3-4周：AI集成与C++通信

**目标**：实现AI决策服务，接收C++发送的实时数据，存入数据库。

| 学习内容                 | 具体知识点                                    | 用于完成的任务                  |
| ------------------------ | --------------------------------------------- | ------------------------------- |
| **HTTP客户端（OkHttp）** | 发送POST请求、设置Header、处理响应            | 调用DeepSeek API                |
| **JSON处理（Jackson）**  | 对象与JSON互转、`@JsonProperty`、解析树模型   | 解析AI返回的JSON，封装请求/响应 |
| **Spring Boot接收JSON**  | `@RequestBody`、`@ResponseBody`、自定义POJO   | 接收C++ POST的实时数据          |
| **AI提示词工程**         | 设计有效Prompt、系统角色设定、temperature调整 | 让AI返回符合格式的窗口分配策略  |
| **缓存（Caffeine）**     | 简单配置、`@Cacheable`                        | 减少AI调用频率，提升响应速度    |
| **降级策略设计**         | try-catch回退、默认规则算法                   | AI失败时保证系统不崩溃          |
| **MySQL JSON类型**       | 将AI请求/响应存入JSON字段                     | 记录AI决策日志                  |

**第4周结束检查点**：
- [ ] 能通过OkHttp调用DeepSeek API，并解析返回的JSON
- [ ] 已实现`POST /api/ai/decision`接口，可根据C++发送的状态返回分配策略
- [ ] 已实现`POST /api/simulation/data`接口，能接收C++数据并存入MySQL
- [ ] 与C++合作者完成首次数据发送联调

---

### 第5-6周：前端基础与静态页面开发

**目标**：学会HTML/CSS/JavaScript基础，能写出配置管理页面，并调用后端API。

| 学习内容           | 具体知识点                                   | 用于完成的任务                        |
| ------------------ | -------------------------------------------- | ------------------------------------- |
| **HTML5基础**      | 常用标签（div、table、form、button）、语义化 | 构建页面结构                          |
| **CSS3基础**       | 选择器、盒模型、Flex布局、Grid布局           | 美化页面，实现响应式                  |
| **JavaScript基础** | 变量、函数、DOM操作、事件监听、Promise       | 动态交互，发送AJAX请求                |
| **Axios**          | 发送GET/POST请求，处理响应                   | 调用后端API（配置管理、获取实时数据） |
| **Bootstrap 5**    | 栅格系统、表格、按钮、模态框                 | 快速搭建美观的配置管理界面            |
| **ECharts基础**    | 引入ECharts、绘制简单柱状图                  | 后续实时监控图表准备                  |

**第6周结束检查点**：
- [ ] 能独立写一个简单的HTML页面，包含表格和按钮
- [ ] 能用Axios从后端获取配置列表并显示在表格中
- [ ] 实现了新建配置的模态框，点击保存能调用后端API
- [ ] 页面布局基本可用（Bootstrap风格）

---

### 第7-8周：前端动态数据与AI可视化

**目标**：实现实时监控页面，动态刷新图表，展示AI决策。

| 学习内容                            | 具体知识点                                           | 用于完成的任务                        |
| ----------------------------------- | ---------------------------------------------------- | ------------------------------------- |
| **ECharts进阶**                     | 动态更新数据（`setOption`）、定时刷新、多系列        | 窗口排队柱状图实时更新                |
| **Canvas/Grid绘制餐桌**             | 用CSS Grid绘制网格，用背景色表示状态；或用Canvas绘制 | 餐桌占用可视化                        |
| **JavaScript定时器（setInterval）** | 轮询后端获取最新数据                                 | 实现每秒刷新                          |
| **异步编程**                        | async/await、Promise.all                             | 同时请求多个API（窗口状态、餐桌状态） |
| **WebSocket基础**（可选）           | 建立连接、监听消息                                   | 如果追求更实时体验，可替代轮询        |
| **前端调试**                        | 浏览器开发者工具（Console、Network、Sources）        | 排查前端问题                          |

**第8周结束检查点**：
- [ ] 实时监控页面能每1秒从后端获取最新数据
- [ ] 柱状图随着排队长度变化动态更新
- [ ] 餐桌网格能正确显示占用/空闲状态
- [ ] AI建议面板能显示从后端获取的分配策略，点击“解释”弹出详细内容

---

| 学习内容                | 具体知识点                               | 用于完成的任务                   |

| **表格数据展示**        | 动态生成表格，格式化数字                 | 显示详细统计结果                 |
| **前端路由（可选）**    | 如果页面复杂，可用原生JS实现简单hash路由 | 切换标签页                       |

**第9周结束检查点**：
- [ ] 能通过API获取多个配置的统计结果
- [ ] 用柱状图展示对比数据，图例清晰
- [ ] 表格显示每个配置的详细指标

---

### 第10-11周：集成测试与优化

**目标**：系统联调，修复Bug，优化性能。

| 学习内容           | 具体知识点                               | 用于完成的任务       |
| ------------------ | ---------------------------------------- | -------------------- |
| **后端调试**       | 日志级别（DEBUG/INFO）、断点调试（IDEA） | 定位后端问题         |
| **前端性能优化**   | 减少DOM操作、节流防抖                    | 保证动画流畅         |
| **数据库索引优化** | 分析慢查询（EXPLAIN），添加索引          | 提高实时数据查询速度 |
| **压力测试**       | 使用JMeter或Postman模拟并发请求          | 检查系统稳定性       |

**第11周结束检查点**：
- [ ] 系统在长时间运行下无内存泄漏
- [ ] AI调用失败时自动降级，界面有提示
- [ ] 数据库查询响应快（<100ms）

---

### 第12-16周：文档、打包与部署

**目标**：编写文档，将系统部署到服务器，准备演示。

| 学习内容              | 具体知识点                           | 用于完成的任务                  |
| --------------------- | ------------------------------------ | ------------------------------- |
| **Markdown**          | 标题、列表、代码块、表格             | 撰写项目文档（README、API文档） |

| **Linux基础命令**     | SSH连接、文件操作、进程管理、systemd | 在服务器上运行后端、C++引擎     |

| **systemd服务**       | 编写.service文件，设置开机自启       | 保证后端和C++引擎稳定运行       |
| **HTTPS配置**（可选） | 使用Let's Encrypt申请证书            | 提高安全性                      |
| **演示技巧**          | 录制视频、制作PPT                    | 最终答辩                        |

**第16周结束检查点**：
- [ ] 所有文档齐全（用户手册、部署说明、API文档）
- [ ] 系统能在新服务器上一键部署（脚本）
